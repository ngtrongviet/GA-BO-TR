# GA-BO-TR

A hybrid optimization framework combining **Genetic Algorithms (GA)**, **Bayesian Optimization (BO)**, and **Trust Regions (TuRBO)** for high-dimensional black-box optimization.

Built with:

* Python
* PyTorch
* BoTorch
* GPyTorch
* NumPy / SciPy

## Overview

GA-BO-TR combines the global exploration of Genetic Algorithms with the sample efficiency of Bayesian Optimization and the local search of Trust Regions.

The project includes experiments on high-dimensional black-box benchmark functions and comparisons with existing optimization methods.
